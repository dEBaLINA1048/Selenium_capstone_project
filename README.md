📌 Project Overview
This project demonstrates end-to-end automation testing of an 
e-commerce web application using Selenium WebDriver with Python. 
It simulates a real-world customer journey from login/signup to 
product selection and cart verification.

--------------------------------------------------------------

🎯 Objective
To automate core functionalities of an e-commerce platform and 
validate the workflow using efficient test automation techniques.

--------------------------------------------------------------

🌐 Application Under Test
https://automationexercise.com/

--------------------------------------------------------------

🔄 Workflow
1. Launch browser  
2. Navigate to application  
3. Signup / Login handling  
4. Search product  
5. Open product details  
6. Add product to cart  
7. Update quantity  
8. View cart  
9. Verify product name & quantity  

--------------------------------------------------------------

🧩 Key Features
✔️ Handles both new and existing users  
✔️ Automates product search and selection  
✔️ Performs cart operations (add/update/verify)  
✔️ Handles dynamic elements (ads/popups)  
✔️ Ensures smooth execution flow
